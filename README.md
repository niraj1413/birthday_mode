# birthday_mode

A celestial, starlit birthday celebration web application 🌸✨

## 🌟 Highlights & Features
- **Starlit Celestial Theme**: Deep navy/night sky backdrop, glowing crescent moon, twinkling and shooting stars canvas animation.
- **Background Music**: Plays Behka Piano Cover softly by default (`audio/behka_piano_cover.mp3`).
- **Interactive Cutout Puppy**: Playful animated jumping black lab puppy celebrating with a cake, dynamic bouncing shadow, speech bubble, and confetti.
- **Scratch Cards**: 5 custom celebratory scratch-off cards.
- **Handwritten Letter**: Beautiful stationery sliding out from a vintage wax-sealed envelope.
- **Frames of You (Polaroids)**: 5 photos with tap-to-reveal blur and dedicated songs for each photo:
  1. *Tere Naina 💫*
  2. *Aankhein Teri Kitni Haseen 🤍*
  3. *There's Something About The Moon 🌙*
  4. *Itni Kyu Tum Khubsurat Ho 🤌💗*
  5. *Behka (Flashback) 🌙✨*
- **Dream Clouds & Star Finale**: Interactive clouds revealing special sentiments, concluding in a celebratory birthday star message.

## 🚀 Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080/index.html`.
